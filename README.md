## Publishing portfolio content

The admin studio publishes through Supabase; it does not save portfolio content or media to browser storage. Before using it, run [`supabase/migrations/20261108010000_portfolio_content_and_media.sql`](./supabase/migrations/20261108010000_portfolio_content_and_media.sql) in the Supabase SQL Editor for the project configured in `admin.js`. The migration creates the public-readable, owner-writeable content table and the public-read, owner-writeable `portfolio-media` image bucket. Storage uploads are limited to 8 MB per JPEG, PNG, WebP, or GIF.

The migration restricts publishing and media changes to `sooryavanshibhawishya@gmail.com`. Configure Google OAuth and the Supabase redirect URL for the deployed admin page as before. If the migration has not been applied, the public site continues to render its built-in portfolio content and the admin shows the Supabase error instead of reporting a successful publish.
